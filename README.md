# Cisco Packet Tracer Korporativ Tarmoq Platformasi

Bu loyiha GitHub Pages uchun tayyor statik platforma: HTML, CSS, JavaScript.

## Kirish loginlari
- Admin: `admin` / `admin123`
- O‘qituvchi: `teacher1` / `teacher123`
- Talaba: `student1` / `student123`

Parol login oynasida oddiy `password` maydonida kiritiladi, matn ko‘rinmaydi.

## GitHub Pagesga qo‘yish
1. GitHub’da yangi repository oching.
2. `index.html`, `style.css`, `app.js`, `README.md` fayllarini yuklang.
3. Repository Settings → Pages bo‘limiga kiring.
4. Branch: `main`, Folder: `/root` qilib Save bosing.
5. 1-2 daqiqadan so‘ng sayt havolasi chiqadi.
